Opening book for engine tests
=============================

`book.epd` holds 5000 positions, one per line, each reached after eight
full moves of a balanced opening. They are a random (fixed-seed) sample
of the 34,700 openings in `8moves_v3.pgn` from the Stockfish project's
book collection at https://github.com/official-stockfish/books, which
was for many years the standard short-time-control book on fishtest.
The openings were generated by Stockfish self-play and filtered for
balance.

This is a book for the test arbiter (fastchess or cutechess-cli), not
for the engine: the arbiter sets both engines on a position from it and
they think from there. Superpawn has no opening book of its own.

Every test described in `TESTING.md` uses this file, so results stay
comparable. Do not edit it; if a different book is ever wanted, add it
as a new file and start a new baseline.
